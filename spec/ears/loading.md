# Loading a course

| Id       | Pattern  | Requirement                                                                                                                                                                                                                        |
| -------- | -------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| STU-0065 | event    | When a lecturer loads a folder that already holds a Tutors course, the Studio shall open it as it is and write nothing.                                                                                                            |
| STU-0066 | event    | When a lecturer loads a folder of their own material, the Studio shall create a new course with a topic for each week the names give, each recognised file in its own learning object, and leave the folder they loaded unchanged. |
| STU-0067 | unwanted | If a loaded folder holds nothing Studio can place in a week, then the Studio shall say what it looks for and create nothing.                                                                                                       |
