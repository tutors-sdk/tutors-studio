# Course details and card pictures

| Id       | Pattern    | Requirement                                                                                                                                                                                            |
| -------- | ---------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| STU-0104 | event      | When a lecturer changes the course's title or credits, the Studio shall show a plan that rewrites only the course page's title line and the credits line in properties.yaml.                           |
| STU-0105 | event      | When a lecturer gives the course a start date, the Studio shall show a plan that writes a calendar dating each week of the course from that day.                                                       |
| STU-0106 | event      | When a lecturer chooses a picture for a card, the Studio shall show a plan that copies it into the item's folder, moves any earlier picture to the bin, and takes out an icon that would show instead. |
| STU-0107 | unwanted   | If a lecturer chooses a file that is not a picture for a card, then the Studio shall change nothing and name the kinds of file a card can show.                                                        |
| STU-0108 | ubiquitous | The Studio shall name a card's picture by its file name and never draw it.                                                                                                                             |
