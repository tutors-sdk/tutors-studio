# Quizzes, slides and diagrams

| Id       | Pattern | Requirement                                                                                                                                            |
| -------- | ------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| STU-0012 | event   | When a lecturer opens a course, the Studio shall check every Mermaid diagram with the Mermaid the reader draws with and list each one that won't draw. |
| STU-0013 | event   | When a lecturer selects a Talk that holds a Marp deck, the Studio shall show the deck's slides as Marp renders them for the reader.                    |
| STU-0014 | event   | When a lecturer selects a folder whose pages hold Mermaid diagrams, the Studio shall show each diagram with the line of the page it starts on.         |
| STU-0015 | event   | When a lecturer opens a course with a quiz question the reader leaves out, the Studio shall name the question and say why it is left out.              |
