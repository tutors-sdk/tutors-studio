# Adding material

| Id           | Pattern    | Requirement                                                                                                                                                                                                                                    |
| ------------ | ---------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| STU-0026     | ubiquitous | The Studio shall show each folder on the course map by the title its card shows, and by its folder name when it has none.                                                                                                                      |
| STU-0027     | event      | When a lecturer drops files on a topic, the Studio shall propose a plan that puts each file it recognises in its own learning object of the kind Tutors shows it as.                                                                           |
| STU-0028     | event      | When a lecturer drops a folder of material on the course, the Studio shall propose placing each item in the topic for the week its name gives.                                                                                                 |
| ~~STU-0029~~ | unwanted   | ~~If Studio can't tell what a dropped file is or which topic it belongs in, then the Studio shall leave it in the tray with the reason and place nothing for it.~~ Retired 2026-11-10: every file is now kept (feature 4); STU-0120, STU-0121. |
| STU-0120     | unwanted   | If nothing in a dropped file's name says which week it is for, or the course has no topic for that week, then the Studio shall leave it in the tray with the reason and place nothing for it.                                                  |
| STU-0121     | event      | When a lecturer drops a file of a kind Tutors doesn't show, the Studio shall keep it, unopened, in the working-files folder where it was dropped, which the course map then flags in the rules' own words.                                     |
