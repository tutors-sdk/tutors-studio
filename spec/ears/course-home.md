# Course home and recent courses

| Id       | Pattern    | Requirement                                                                                                                                           |
| -------- | ---------- | ----------------------------------------------------------------------------------------------------------------------------------------------------- |
| STU-0127 | event      | When a lecturer opens or makes a course, the Studio shall put it first among the start screen's courses, each course once and at most eight.          |
| STU-0128 | event      | When Studio starts, the Studio shall reopen the course open last, or, if its folder has gone, drop it from the list and say so.                       |
| STU-0129 | ubiquitous | The Studio shall show each week on the course home as needing sorting out, empty so far, still to write, or written.                                  |
| STU-0130 | event      | When files in the open course change on disk, in Studio or another app, the Studio shall read the course again and show the change on the course map. |
| STU-0148 | event      | When a lecturer forgets a course on the start screen, the Studio shall take it off the list and leave its folder and files as they are.               |
| STU-0149 | event      | When a lecturer puts back a course they have just forgotten, the Studio shall list it where it was.                                                   |
