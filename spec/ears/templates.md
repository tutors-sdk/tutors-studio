# Starting from a template

Starter templates are whole courses to start from, beside the guided questions: the Lecture and lab template (ADR 0039) and reference courses shaped on real Tutors courses (ADR 0041).

| Id           | Pattern    | Requirement                                                                                                                                                                                                                                                                                                             |
| ------------ | ---------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ~~STU-0150~~ | ubiquitous | ~~The Studio shall offer a starter template for each kind of module, each modelled on a topic of the Tutors reference course and each in 2, 4, 6, 8, 10 and 12 week lengths.~~ Retired 2026-11-14: Leigh found five templates too many; reference courses in a list and one template replace them (ADR 0041, STU-0162). |
| STU-0151     | event      | When a lecturer names a course and picks a template and a length, the Studio shall create a course that checks with no errors, with one week per teaching week holding what the template's week holds.                                                                                                                  |
| STU-0152     | event      | When a lecturer picks a template of six weeks or more, the Studio shall group the weeks into sections and make the last week a review with a quiz.                                                                                                                                                                      |
| STU-0153     | unwanted   | If the template or the length a lecturer asks for is not one Studio offers, then the Studio shall name each answer to change and create nothing.                                                                                                                                                                        |
| STU-0154     | event      | When a lecturer opens a course made from a template, the Studio shall show every week as still to write.                                                                                                                                                                                                                |
| STU-0162     | ubiquitous | The Studio shall offer three ways to start a new course: a reference course picked from a list, the Lecture and lab template in 2, 4, 6, 8, 10 or 12 weeks, and a week the lecturer shapes.                                                                                                                             |
| STU-0163     | event      | When a lecturer names a course and picks a reference course, the Studio shall create a course that checks with no errors and holds every week, unit, item and lab step of the course it is shaped on, titled as that course titles them.                                                                                |
