# Guided building

A first-time lecturer is walked through a new course, week by week and item by item, and every item asks for the material it takes: slides for a talk, content for a lab. A complement to the free-form course map, not a replacement (ADR 0071).

| Id       | Pattern    | Requirement                                                                                                                                                                                                                          |
| -------- | ---------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| STU-0341 | ubiquitous | The Studio shall offer on each talk, tutorial, lab, reading and archive an upload button that names what that item takes.                                                                                                            |
| STU-0342 | event      | When a lecturer uploads a PDF to a talk or a tutorial, the Studio shall put it in that item and move the slides it showed before to the bin.                                                                                         |
| STU-0343 | unwanted   | If a lecturer uploads anything but one PDF to a talk or a tutorial, then the Studio shall upload nothing and say what to upload instead.                                                                                             |
| STU-0344 | event      | When a lecturer uploads content to a lab, the Studio shall make each Markdown page a step, in the order of their names and in place of steps that still hold starter text, and keep every other file where the steps' links find it. |
| STU-0345 | event      | When a lecturer uploads to a reading, the Studio shall make a Markdown page the reading and attach every other file with a link from it.                                                                                             |
| STU-0346 | unwanted   | If a lecturer uploads a page to a reading they have already written, then the Studio shall upload nothing and say why.                                                                                                               |
| STU-0347 | event      | When a lecturer uploads a file to an archive, the Studio shall make it the archive's download, zipped when it is not a zip.                                                                                                          |
| STU-0348 | optional   | Where a lecturer asks to be guided when making a new course, the Studio shall open the course at the guide's first step.                                                                                                             |
| STU-0349 | ubiquitous | The Studio's guide shall take the lecturer through each week in order, naming the week and then adding material to each of its items, and end with a check of the course.                                                            |
| STU-0350 | event      | When a week has its own title or an item has its material, the Studio's guide shall count that step as done and go on to the next step not done.                                                                                     |
| STU-0351 | event      | When a lecturer skips a step, the Studio's guide shall go on to the next step not done and list the skipped step as still to do at the end.                                                                                          |
| STU-0352 | event      | When a lecturer goes back to the guide on a course, the Studio shall start it at the first step not done.                                                                                                                            |
