# Running the term

| Id       | Pattern | Requirement                                                                                                                                                                                                                |
| -------- | ------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| STU-0196 | state   | While a course has a calendar, the Studio shall show the current teaching week first on the course home.                                                                                                                   |
| STU-0197 | event   | When a lecturer gives a week a release date, the Studio shall show a plan that hides the week and keeps the date beside it in properties.yaml.                                                                             |
| STU-0198 | event   | When a week's release date has arrived and the week is still hidden, the Studio shall offer to publish it and show the change as a plan.                                                                                   |
| STU-0199 | event   | When a lecturer starts next year from a course, the Studio shall make a new course folder with the same content and outcomes, no release dates, and a calendar from the new first Monday, and leave this course as it was. |
