# Getting around

Back and Home wherever the lecturer is, in Studio and in its Tutors window, so no screen is a dead end.

| Id       | Pattern    | Requirement                                                                                                                                      |
| -------- | ---------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| STU-0325 | ubiquitous | The Studio shall show Back, which closes the screen on top as its own Close would, and Home, which returns to the start screen, on every screen. |
| STU-0326 | ubiquitous | The Studio's Tutors window shall show Back, one page back, and Home, the Tutors reader's home page, on every page.                               |
