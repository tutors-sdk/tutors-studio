# Plain names

| Id       | Pattern    | Requirement                                                                                                                                                                                                                                                            |
| -------- | ---------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| STU-0059 | ubiquitous | The Studio shall offer what a lecturer can add by the lecturer's own words, and map each word to the kind Tutors reads from a folder's name.                                                                                                                           |
| STU-0060 | event      | When a lecturer adds a lecture, lab, reading, link or code repository to a week by its plain name and a title, the Studio shall propose a plan that makes the folder Tutors reads and its first files.                                                                 |
| STU-0061 | event      | When a lecturer adds a week to the course or to a unit, the Studio shall propose a plan that makes the next numbered topic titled as the lecturer typed it.                                                                                                            |
| STU-0062 | unwanted   | If the lecturer's word, title, address or place can't make an item, then the Studio shall say what to change and propose no plan.                                                                                                                                      |
| STU-0068 | event      | When a lecturer makes a folder students can't see into a lecture, lab, reading or week by its plain name, the Studio shall propose a plan that renames the folder to the kind Tutors reads, keeps everything inside it, and adds only the files that kind still needs. |
| STU-0069 | event      | When a lecturer makes a folder of pages into a lab, the Studio shall propose numbering its unnumbered pages as steps, in name order, after any steps it already has.                                                                                                   |
| STU-0070 | unwanted   | If the lecturer's word can't make the folder something students see where it sits, then the Studio shall say which words can and propose no plan.                                                                                                                      |
| STU-0071 | state      | While a folder Tutors leaves out has a name that declares no kind, the Studio shall leave the lecturer to choose what it is, and offer no rename that picks the kind for them, alone or among the safe fixes.                                                          |
