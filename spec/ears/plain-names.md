# Plain names

| Id       | Pattern    | Requirement                                                                                                                                                                                            |
| -------- | ---------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| STU-0059 | ubiquitous | The Studio shall offer what a lecturer can add by the lecturer's own words, and map each word to the kind Tutors reads from a folder's name.                                                           |
| STU-0060 | event      | When a lecturer adds a lecture, lab, reading, link or code repository to a week by its plain name and a title, the Studio shall propose a plan that makes the folder Tutors reads and its first files. |
| STU-0061 | event      | When a lecturer adds a week to the course or to a unit, the Studio shall propose a plan that makes the next numbered topic titled as the lecturer typed it.                                            |
| STU-0062 | unwanted   | If the lecturer's word, title, address or place can't make an item, then the Studio shall say what to change and propose no plan.                                                                      |
