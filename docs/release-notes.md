## Install Tutors Studio {{version}}

Download the one file for your computer and open it. No administrator rights or other software needed.

| Your computer                | Download                          |
| ---------------------------- | --------------------------------- |
| Mac (Intel or Apple silicon) | `Tutors-Studio-macOS.dmg`         |
| Windows 10 or 11             | `Tutors-Studio-Windows-setup.exe` |
| Ubuntu, Debian or Mint       | `Tutors-Studio-Linux.deb`         |
| Any other Linux              | `Tutors-Studio-Linux.AppImage`    |

{{signing}}

Step-by-step help, with what to click on each computer: [Installing Tutors Studio](https://github.com/tutors-sdk/tutors-studio/blob/main/docs/install.md).

IT departments: `Tutors-Studio-Windows.msi` installs for every user of a machine; `SHA256SUMS.txt` checks the downloads.

Every file here was installed and opened on a clean macOS, Windows, Ubuntu 22.04 and Ubuntu 24.04 machine before this release was made.
