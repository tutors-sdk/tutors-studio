Tutors Studio

Build a Tutors course on your own computer. Studio shows it the way Tutors will publish it, says in plain words what is missing, and fixes it with you.

Web Development II, built in a minute and a half

What the film shows
  1. Start a new course and name it Web Development II.
  2. Start from the Web Development II reference course: eight weeks of lectures and labs, with their titles.
  3. Studio shows the course the way Tutors will publish it. It already passes Tutors' checks.
  4. Open week 1 and drop two lecture PDFs onto it. Each becomes a lecture card, with Put it back if you change your mind.
  5. Write the week's page the way you would in a word processor, and save it.
  6. Changes lists every change, and each one can be put back.
  7. Check and publish says the course is ready to publish.

Every step is in the Web Development II walkthrough.
